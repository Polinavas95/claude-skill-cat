# CatPet — кот из cat-skill поверх рабочего стола (macOS)

Прозрачное окно на весь экран поверх остальных окон. Клики проходят сквозь него везде,
кроме кота: клик по коту — погладить. Кот видит настоящий курсор по всему экрану.
Иконка в строке меню (силуэт кошачьей головы) — меню действий и выход.

## Запуск

Готовое приложение: `dist/CatPet-darwin-arm64/CatPet.app` — двойной клик.
Приложение подписано ad-hoc (без сертификата разработчика): на этом Mac запускается,
на чужом Gatekeeper попросит разрешить в «Системные настройки → Конфиденциальность».

Из исходников:

    npm install
    npm start

## Свой кот: внешность, характер, пол

Приложение читает описание кота из файла `cat.json` в своей папке данных
(`~/Library/Application Support/CatPet/cat.json`). При первом запуске туда копируется
`cats/shinshilla.json`.

Как поменять кота:

1. Правый клик по коту (или значок с именем кота в строке меню) → **«Изменить кота (cat.json)…»**.
   Файл откроется в редакторе. Сохрани — кот перечитается сам, перезапуск не нужен.
2. Или **«Выбрать другой cat.json…»** и указать готовый файл. Примеры лежат в `cats/`.
3. **«Сменить пол»** переключает кота и кошку на лету (и запоминается).

Схема `cat.json`, палитры окрасов, породы и перевод характера в числа — в
`cat-skill/references/pet-spec.md`. Породы (`breed`) и готовые окрасы (`whiskas`, `black_and_tan`)
приложение раскладывает само, как сборщик скилла. Если JSON сломан, покажется окно с ошибкой,
а кот останется прежним.

Кратко: `sex` — `male`/`female`; `appearance.base_color`, `eye_color`, `pattern`, `fur`, `build`,
`face`, `tail`, `extras`; `personality.energy/curiosity/boldness/clinginess/talkativeness/loaf_bias`
от 0 до 1; `scale` — размер, `speed_scale` — скорость.

## Как устроено

- `main.js` — окно (transparent, frameless, alwaysOnTop, click-through), опрос курсора
  60 раз/с через `screen.getCursorScreenPoint`, иконка в строке меню, IPC.
- `preload.js` — мост `window.pet` между главным процессом и страницей.
- `build_pet_app.py` — берёт движок из `cat-skill/assets/pet.template.html` и делает из него
  `pet.template.html` для оверлея (плюс `breeds.json` с породами): без нарисованного стола, пол у низа
  экрана, курсор из главного процесса, состояния «иконки» отключены (на настоящем
  экране их не видно), прятки — только за край экрана. Конкретного кота подставляет
  `main.js` при запуске и при каждом изменении `cat.json`.
- Размер: в оверлее кот в 2.5 раза меньше, чем в HTML-версии; `scale` в cat.json остаётся множителем.
- Память кота (место, пол, поглаживания) — в localStorage приложения, как и в HTML-версии.
