# Спецификация питомца — `cat.json`

Один файл описывает кота целиком. Движок читает только перечисленные ниже поля;
незнакомые поля `build_pet.py` пропускает с замечанием.

## Полная схема

```json
{
  "name": "Мурзик",
  "sex": "male",
  "language": "ru",
  "scale": 1.0,
  "speed_scale": 1.0,
  "appearance": {
    "base_color": "#d9a15a",
    "pattern": "tabby",
    "pattern_color": "#a5672c",
    "belly_color": "#f8e6cd",
    "eye_color": "#7fb069",
    "nose_color": "#e08b9b",
    "inner_ear_color": "#f0b8c0",
    "fur": "medium",
    "ear_style": "normal",
    "tail": "fluffy",
    "build": "chonky",
    "extras": ["white_socks", "chest_spot"],
    "collar_color": "#c0392b",
    "eye_color2": "#8fc7e8",
    "tan_color": "#b8763a"
  },
  "personality": {
    "energy": 0.6, "curiosity": 0.75, "boldness": 0.35,
    "clinginess": 0.6, "talkativeness": 0.7, "loaf_bias": 0.5
  },
  "phrases": {
    "meow": ["Мяу", "Мяяу"], "purr": ["Мур-р-р"], "scared": ["Ш-ш-ш!"],
    "eat": ["Хрум"], "sleep": ["z-z-z"], "annoyed": ["Мрм."]
  }
}
```

Обязательны `name` и `appearance.base_color`. Остальное имеет разумные значения по умолчанию.

## Поля

| Поле | Значения | Что делает |
|---|---|---|
| `name` | строка | Имя в заголовке страницы. |
| `sex` | `male`, `female` | У кошки — реснички у глаз. У кота — чуть заметная деталь под хвостом, видимая только когда он разворачивается. |
| `language` | `ru`, `en` | Язык фраз по умолчанию; `phrases` важнее. |
| `scale` | 0.5–2.0 | Размер кота на сцене. |
| `speed_scale` | 0.3–2.0 | Множитель скорости. Отдельно от `energy`: `energy` решает, как часто кот двигается, `speed_scale` — как быстро. |

### `appearance`

| Поле | Значения | Примечание |
|---|---|---|
| `base_color` | hex | Основной цвет шерсти. От него же считается цвет контура. |
| `pattern` | `solid`, `tabby`, `mackerel`, `spotted`, `tuxedo`, `bicolor`, `tortie`, `calico`, `point` | См. палитры ниже. |
| `pattern_color` | hex | Полосы, пятна, маска. Обычно на 25–40% темнее основного. |
| `belly_color` | hex | Грудь и живот; на спине он же виден, когда кот спит кверху брюхом. |
| `eye_color` | hex | Внутри движок делает радужку светлее и добавляет тень и блики. |
| `nose_color` | hex | Розовый `#e08b9b` для светлых, `#4a3b3b` для чёрных. |
| `inner_ear_color` | hex | По умолчанию выводится из основного цвета. |
| `fur` | `short`, `medium`, `long` | `long` — пушистее контур и толще хвост. |
| `ear_style` | `normal`, `large`, `folded`, `tufted` | `folded` — вислоухий, `tufted` — с кисточками. |
| `tail` | `long`, `fluffy`, `short`, `bobtail` | Длина и толщина; поднятый хвост загибается крючком. |
| `build` | `slim`, `normal`, `chonky` | Длина и высота корпуса. |
| `extras` | список | `white_socks`, `chest_spot`, `white_muzzle`, `white_tail_tip`, `collar`, `heterochromia`, `notched_ear`, `scar`, `tan_points`, `pirate_hat` |
| `collar_color` | hex | Работает при `collar` в `extras`. |
| `eye_color2` | hex | Цвет второго глаза при `heterochromia`; без него второй глаз голубой. |
| `tan_color` | hex | Цвет подпалин при `tan_points`; без него — рыжеватый оттенок основного. |

### Приметы (`extras`)

| Примета | Что рисуется |
|---|---|
| `white_socks` | белые лапки |
| `chest_spot` | белое пятно на груди |
| `white_muzzle` | белая морда |
| `white_tail_tip` | белый кончик хвоста |
| `collar` | ошейник цвета `collar_color` |
| `heterochromia` | глаза разного цвета: `eye_color` и `eye_color2` |
| `notched_ear` | рваное ухо — выемка на внешнем крае ближнего уха |
| `scar` | шрам через ближний глаз: косая линия со стежками; на тёмной шерсти светлый, на светлой — тёмный |
| `tan_points` | подпалины: точки над глазами, щёки, грудь и лапы цвета `tan_color` (чёрно-подпалый окрас) |
| `pirate_hat` | чёрная пиратская треуголка с черепом и костями, чуть набекрень; закрывает макушку |

У табби и макрели на лбу всегда рисуется фирменная «M».

### `personality` (все 0.0–1.0)

| Поле | 0.0 | 1.0 |
|---|---|---|
| `energy` | почти всё время лежит | почти не стоит на месте, чаще срывается в берсерк |
| `curiosity` | иконки игнорирует | лезет к каждой, чаще прыгает наверх, чаще принюхивается |
| `boldness` | пугается любого рывка курсора | почти не пугается, крепче держится за курсор, чаще демонстративно не реагирует |
| `clinginess` | к курсору равнодушен | постоянно идёт к курсору и цепляется |
| `talkativeness` | молчит | часто мяукает и мурчит |
| `loaf_bias` | отдыхает сидя | отдыхает буханкой и спит |

### `phrases`

Ключи: `meow`, `purr`, `scared`, `sleep`, `eat`, `annoyed`. Списки строк, кот берёт случайную.
До 10 символов — длиннее не влезает в пузырь. Характерные звуки конкретного кота
(«Мрм», «Э-э!», «Ва-у») вписывать стоит: именно они дают узнаваемость.

## Палитры окрасов

| Реальный кот | `pattern` | Цвета |
|---|---|---|
| Рыжий полосатый | `tabby` | base `#e0a35c`, pattern `#b06a28`, belly `#f8e6cd` |
| Серый полосатый | `tabby` | base `#9aa0a6`, pattern `#5f6469`, belly `#d7dade` |
| Тонкие ровные полосы | `mackerel` | те же цвета, полос больше и тоньше |
| Пятнистый | `spotted` | пятна вместо полос |
| Чёрный с белой грудкой и лапами | `tuxedo` | base `#2e2b2e`, belly `#f4f4f2`, extras `white_socks`, `chest_spot` |
| Двухцветный | `bicolor` | base цветной, belly `#f7f7f5` |
| Черепаховая | `tortie` | base `#3a3336`, pattern `#c9762f` |
| Трёхцветная | `calico` | base `#f6f2ea`, pattern `#c9762f` |
| Сиамский | `point` | base `#efe0cc`, pattern `#5a4436`, eye `#8fc7e8` |
| Белый | `solid` | base `#f6f4f0`, nose `#e8a0a8` |
| Чёрный | `solid` | base `#2b2830`, eye `#e0a030`, nose `#4a3b3b` |
| «Вискас»-табби (серо-бурые полосы, белая грудь и лапы) | `whiskas` | base `#8a7460`; сборщик сам разложит на `mackerel` + `white_socks`, `chest_spot`, `white_muzzle` |
| Чёрный с подпалинами | `black_and_tan` | base `#2b2830`, tan `#b8763a`; раскладывается на `solid` + `tan_points` |

`pattern` понимает и русские названия этих двух: «вискас», «подпалый».

Даже для однотонного кота ставь `belly_color` на 8–12% светлее основного — иначе силуэт плоский.

## Порода

Отдельной «картинки породы» в движке нет: порода — это набор параметров. Поле `breed`
(строка, необязательное) подставляет пресет; всё, что указано в `appearance` явно, важнее
пресета. Понимаются русские названия: сфинкс, британец, персидская, сиамская, мейн-кун,
норвежская лесная, рэгдолл, манчкин, скоттиш-фолд (вислоухая), бенгальская, абиссинская,
ориентальная, русская голубая, мэнкс, курильский бобтейл, девон-рекс, корниш-рекс, бурма,
сибирская, турецкая ангора, шартрез, экзот, гималайская, бирма, сноу-шу, египетская мау,
саванна, бомбей, тойгер, американская короткошёрстная, нибелунг, сомали, балинез, тонкинез,
турецкий ван, дворовый/метис.

| Порода | Что задаёт пресет |
|---|---|
| `sphynx` (сфинкс) | `fur: hairless`, большие уши, клиновидная морда, длинные лапы, худое тело |
| `british` (британец) | короткая шерсть, `chonky`, приплюснутая морда |
| `persian` (персидская) | длинная шерсть, `chonky`, приплюснутая морда, пушистый хвост |
| `siamese` (сиамская) | окрас `point`, худое тело, клиновидная морда, большие уши |
| `maine_coon` / `norwegian` | длинная шерсть, `chonky`, пушистый хвост, кисточки на ушах |
| `ragdoll` | длинная шерсть, `chonky`, пушистый хвост, окрас `point` |
| `munchkin` | `leg_length: short` |
| `scottish_fold` (вислоухая) | `ear_style: folded`, `chonky`, приплюснутая морда |
| `bengal` | окрас `spotted`, длинные лапы |
| `abyssinian` / `oriental` | худое тело, большие уши, клиновидная морда, длинные лапы |
| `russian_blue` | короткая шерсть, худое тело, клиновидная морда (цвет задавайте сами) |
| `manx` | `tail: bobtail` |
| `bobtail` | `tail: short` |
| `devon_rex` / `cornish_rex` | худое тело, большие уши, клиновидная морда, длинные лапы (кудри движок не рисует) |
| `burmese` / `chartreux` / `american_shorthair` / `bombay` | короткая шерсть, круглая морда; шартрез — `chonky` |
| `siberian` | длинная шерсть, `chonky`, пушистый хвост, кисточки |
| `turkish_angora` / `nebelung` / `somali` | длинная шерсть, худое тело, пушистый хвост, клиновидная морда |
| `exotic` | короткая шерсть, `chonky`, приплюснутая морда |
| `himalayan` | как перс, но окрас `point` |
| `birman` / `snowshoe` / `tonkinese` / `balinese` | окрас `point`; бирма и балинез длинношёрстные. Белые лапки бирмы — `white_socks` в extras |
| `egyptian_mau` / `savannah` | `spotted`, худое тело, длинные лапы |
| `toyger` | `mackerel` |
| `turkish_van` | `bicolor`, средняя шерсть, пушистый хвост |
| `mixed` (дворовый) | ничего не задаёт — заполняйте параметры по фото |

Цвет порода не задаёт никогда: британец бывает и голубым, и рыжим, и вискас-табби.

### Новые поля внешности

| Поле | Значения | Что меняется |
|---|---|---|
| `fur` | + `hairless` | кожа вместо шерсти: корпус суше и длиннее, хвост тонкий, уши крупнее на треть, по груди и бедру идут складки, шерсть при испуге почти не встаёт |
| `face` | `round`, `flat`, `wedge` | `flat` — череп шире и круглее, морда подобрана, нос выше, уши меньше (персы, британцы, вислоухие); `wedge` — череп уже, морда вытянута, уши крупнее (сиамы, ориенталы, куны) |
| `leg_length` | `short`, `normal`, `long` | `short` — манчкин (лапы 55% длины), `long` — ориентал и бенгал (128%) |

Если породу не назвали, `breed` можно не указывать вовсе: `fur`, `build`, `ear_style`,
`tail`, `face` и `leg_length` полностью описывают внешность и без неё.

## Как читать фото

1. **Основной цвет** — самая большая площадь шерсти. Тёплая лампа делает белого кота бежевым:
   ориентируйся на нейтральные участки и не тащи оранжевый отлив в `base_color`.
2. **Узор** — полосы, пятна, маска на морде, резкая граница с белым. Белая грудь и лапы при
   тёмном корпусе — это `tuxedo`, а не `solid`.
3. **Глаза** — со вспышкой часто засвечены. Если непонятно, спроси одним словом или возьми
   янтарный: он идёт почти ко всем окрасам.
4. **Длина шерсти** — по контуру: пушистый «нимб» по краю силуэта и толстый хвост = `long`.
5. **Телосложение** — `chonky`, если живот заметно шире груди. Про вес кота не комментируй,
   это просто параметр формы.
6. **Приметы** дают узнаваемость сильнее, чем точность оттенка: белый носок на одной лапе,
   рваное ухо, пятно на груди, ошейник нужного цвета.

Породу угадывать и сообщать как факт не нужно: порода — вывод, а параметры — то, что видно.

## Характер в числах

```
«Ленивый, целый день спит»       energy .2  curiosity .3  loaf_bias .85
«Котёнок, носится и всё роняет»  energy .95 curiosity .9  loaf_bias .1
«Ходит за мной по квартире»      clinginess .9
«Дикий, боится гостей»           boldness .1  clinginess .2
«Спокойный, ничем не проймёшь»   boldness .9  loaf_bias .6
«Орёт с утра»                    talkativeness .95
```

Если про характер не сказано ничего — ставь всё по 0.5, кроме `boldness` 0.4: пугливость
выглядит живее невозмутимости, а испуг короткий, кот тут же успокаивается.
